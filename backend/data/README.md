# Demo data

This directory contains a synthetic development fixture, not real planetary data. The application uses it so the team can run terrain calculations end to end while verifying NASA/USGS sources and terms.

- `sample_elevation.tif` is a deterministic 100 x 160 synthetic elevation surface generated by `backend/scripts/generate_sample_terrain.py`.
- It has no NASA/USGS provenance and must not be presented as a scientific measurement.
- When a verified small-area elevation raster replaces it, record its source in the repository-level `DATA_SOURCES.md` before using it in route calculations.
